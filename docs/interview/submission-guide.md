# ClientDesk 面试交付说明

## 作品定位

这是一个可本地运行的 React 客户与工单管理后台演示。采用虚构数据与 HTTP Mock，展示两个业务模块、公共组件复用，以及 Claude Code / Codex 在项目规则和自动检查约束下迭代的过程。它不包含真实登录、多租户隔离或生产后端。

## 对照题目四项要求

| 要求 | 作品中的证据 | 面试演示 |
| --- | --- | --- |
| 两个业务模块 CRUD、复用表格表单 | 客户和工单模块均有列表、详情、新增、编辑、删除；共享 `DataTable`、`FormDialog`、`DeleteConfirm` | 新增客户和工单、编辑、查看、删除；展示关联客户不能直接删除 |
| 快速、高质量迭代 | 优先级筛选作为独立增量；统一 `npm run verify` 检查类型、契约、测试、构建和浏览器流程 | 展示下方迭代案例与实际检查结果 |
| 快速前后端协作，可用 Mock | OpenAPI 约定接口，类型由契约生成；MSW 模拟 HTTP、分页及 422/404/409 错误 | 展示契约与 Mock，再指出真实后端替换入口 |
| 可运行项目及 Harness | `npm ci`、`npm run dev` 可启动；`AGENTS.md`、`CLAUDE.md`、`RULES.md`、脚本、固定数据、CI 配置共同构成 Harness | 在新环境按 README 启动，运行 `npm run verify` |

## 从源码包启动

1. 解压交付包并进入项目根目录。
2. 使用 Node 24.19.0、npm 11.17.0，运行 `npm ci`。
3. 运行 `npm run dev`，打开终端提示的本地地址。
4. 如需完整浏览器验证，先运行 `npm exec playwright install chromium`，再运行 `npm run verify`。

依赖和浏览器首次安装需要网络；业务演示及测试不调用第三方业务服务。交付包不含 `node_modules`、构建产物、浏览器报告、个人数据或本地密钥。仓库尚无提交或远端 CI 运行记录，交付包是本地源码快照。

## 5–8 分钟讲解顺序

1. 展示客户和工单两个模块以及共享表格、表单、删除确认。
2. 新建客户和工单，改动工单状态；尝试删除有关联工单的客户，展示 409 业务冲突。
3. 展示优先级筛选与异常场景重试。
4. 打开 OpenAPI、项目规则和检查脚本，讲清前后端与 AI 的协作边界。
5. 展示 `npm run verify` 的实际结果和下方的增量迭代记录。
6. 说明 Mock、单组织和真实后端未验收的限制。

## 一次真实增量：工单优先级筛选

**需求。** 在已完成工单基础 CRUD 后，支持按低、中、高优先级筛选；筛选条件要能与客户、状态组合，刷新页面后保留。

**先观察失败。** 新增三项契约测试。未修改接口时，两个有效筛选用例收到 422 而失败；非法枚举返回 422 的用例通过。这证明原接口确实不支持新参数。

**跨层修改。** 将 `priority` 加入 OpenAPI 查询参数并重新生成 TypeScript 类型；Mock 按交集过滤；前端列表把筛选写入 URL 和查询键，切换条件时回到第一页。

**验证结果。** 三项优先级契约测试随后通过。最终本地完整 `npm run verify` 通过：27 项单元/集成测试、2 项模块边界检查器测试、17 项 Chromium 浏览器测试；静态检查、类型检查、契约漂移、构建及常见密钥模式扫描通过。此后新增工单选择器空值提示做了局部修正，相关 10 项浏览器回归、静态检查、类型检查和演示构建通过。

**没有声称的证据。** Git 远端 CI、真实后端、生产部署和实际面试官设备均未验收。曾尝试手动依赖分包，构建成功但浏览器运行失败，已撤回；主包仍有体积提示。
