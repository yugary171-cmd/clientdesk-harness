## 剩余限制

- 默认构建存在单块大于 500 kB 的体积提示（主包约 1.30 MB，gzip 408 kB；演示 Mock 块约 434 kB）。未做生产性能专项优化。
- 单组织本地演示，无真实鉴权、租户隔离、后端/数据库/生产验收；多人编辑后写覆盖，不保证跨标签页事务一致。
- 真实模式切换的浏览器核对是本次人工验证，尚未自动化进 CI；视觉检查也不等于跨设备兼容性验收。

## 历史

### 2026-10-30：演示页切回错误修复

- 用户反馈切回浏览器后客户列表偶发“服务返回格式异常”，刷新恢复。源码检查确认页面获焦会触发 React Query 自动重取；预览服务器直连 `/api/customers` 返回 HTML，因此 Mock 漏拦截可造成该错误。浏览器在切回瞬间漏拦截的底层原因尚未单独证实。
- 仅在演示模式禁用获焦自动重取；真实 API 模式维持原行为。新增 E2E 回归，验证切回不发请求且手动刷新仍发请求。
